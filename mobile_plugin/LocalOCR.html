命令名称： LocalOCR.SetServer 设置默认OCR服务端地址
命令功能： 设置后续调用使用的默认OCR服务端地址，例如 192.168.1.101:8080。
参数说明：
参数1: 服务端地址(字符串), 例如 "192.168.1.101:8080"
返回值： 无返回值
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
// 设置PC端OCR服务端地址
LocalOCR.SetServer "192.168.1.101:8080"
命令名称： LocalOCR.Ping 测试与服务端是否连通
命令功能： 发送一个测试请求到OCR服务端，判断手机与PC的网络是否通。
参数说明：
参数1: 服务端地址(字符串, 可省略, 使用SetServer默认值)
返回值： 字符串: OK 表示连通; ERROR|错误信息 表示失败
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
LocalOCR.SetServer "192.168.1.101:8080"
Dim ping = LocalOCR.Ping("")
TracePrint ping
命令名称： LocalOCR.RecognizeStr 识别图片中所有文字(字符串版)
命令功能： 把整张图片发到PC服务端识别,返回所有文字和坐标信息,以分号分隔每条结果。
参数说明：
参数1: 服务端地址(字符串, 可省略)
参数2: 图片完整路径(字符串), 例如 /sdcard/screen.png
返回值： 字符串: text|置信度|x|y|w|h|中心x|中心y;text|... 每条结果以 | 分隔字段, 多条结果以 ; 分隔
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
Dim 图片路径 = "/sdcard/screen.png"
SnapShot 图片路径
Dim ret = LocalOCR.RecognizeStr("", 图片路径)
TracePrint ret
Dim lines = Split(ret, ";")
For i = 0 To UBound(lines)
    Dim cols = Split(lines(i), "|")
    If UBound(cols) >= 7 Then
        TracePrint cols(0) & " (" & cols(6) & "," & cols(7) & ")"
    End If
Next
命令名称： LocalOCR.FindTextStr 查找文字并返回点击坐标(字符串版)
命令功能： 在图片中搜索指定关键字,返回找到的中心坐标,用于点击。
参数说明：
参数1: 服务端地址(字符串, 可省略)
参数2: 图片完整路径(字符串)
参数3: 要查找的关键字(字符串)
返回值： 字符串: x|y|置信度|文字 未找到返回 ERROR|未找到 或 ERROR|错误信息
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
Dim 图片路径 = "/sdcard/screen.png"
SnapShot 图片路径
Dim ret = LocalOCR.FindTextStr("", 图片路径, "开始")
If Left(ret, 5) <> "ERROR" Then
    Dim cols = Split(ret, "|")
    Touch cols(0), cols(1)
Else
    TracePrint "未找到"
End If
命令名称： LocalOCR.Recognize 识别图片中所有文字(表格版)
命令功能： 与RecognizeStr功能相同,但返回Lua表格,方便脚本内遍历。
参数说明：
参数1: 服务端地址(字符串, 可省略)
参数2: 图片完整路径(字符串)
返回值： Lua表格数组,每个元素包含 text, confidence, x, y, w, h, center_x, center_y
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
Dim 图片路径 = "/sdcard/screen.png"
SnapShot 图片路径
Dim results = LocalOCR.Recognize("", 图片路径)
For i = 0 To results.Length - 1
    TracePrint results(i)["text"] & " (" & results(i)["center_x"] & "," & results(i)["center_y"] & ")"
Next
命令名称： LocalOCR.FindText 查找文字并返回坐标表格
命令功能： 与FindTextStr功能相同,但返回Lua表格,包含 found/x/y/confidence/text 字段。
参数说明：
参数1: 服务端地址(字符串, 可省略)
参数2: 图片完整路径(字符串)
参数3: 关键字(字符串)
返回值： Lua表格: {found=true/false, x=..., y=..., confidence=..., text=..., error=...}
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
Dim 图片路径 = "/sdcard/screen.png"
SnapShot 图片路径
Dim ret = LocalOCR.FindText("", 图片路径, "开始")
If ret["found"] = True Then
    Touch ret["x"], ret["y"]
Else
    TracePrint ret["error"]
End If
命令名称： LocalOCR.SetScreenshotPath 设置区域查找时临时截图路径
命令功能： 设置FindAt/FuzzyFindAt在区域内截图保存的临时文件路径。
参数说明：
参数1: 图片路径(字符串), 例如 /sdcard/LocalOCR_region.png
返回值： 无
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
LocalOCR.SetScreenshotPath "/sdcard/LocalOCR_region.png"
命令名称： LocalOCR.ocr 区域内精确查找文字并可选点击
命令功能： 在指定屏幕区域内截图,精确查找目标文字。找到后可选自动点击,坐标保存在 LastFindX/LastFindY。
参数说明：
参数1-4: 区域左上角/右下角坐标(x1,y1,x2,y2)
参数5: 要查找的文字(字符串)
参数6: 是否点击(1=点击, 0=不点击)
返回值： true=找到, false=未找到。点击坐标写入 LocalOCR.LastFindX / LocalOCR.LastFindY
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
LocalOCR.SetServer "192.168.1.101:8080"
If LocalOCR.ocr(100, 200, 400, 500, "开始", 1) = True Then
    TracePrint "点击了 " & LocalOCR.LastFindX & "," & LocalOCR.LastFindY
Else
    TracePrint "未找到"
End If
命令名称： LocalOCR.ocra 区域内模糊查找文字并可选点击
命令功能： 在指定屏幕区域内截图,查找包含目标关键字的文字。找到后可选自动点击。
参数说明：
参数1-4: 区域坐标(x1,y1,x2,y2)
参数5: 关键字(字符串)
参数6: 是否点击(1=点击, 0=不点击)
返回值： true=找到, false=未找到。点击坐标写入 LocalOCR.LastFindX / LocalOCR.LastFindY
脚本示例：
此为安卓手机语法 
Import "LocalOCR.lua"
If LocalOCR.ocra(100, 200, 400, 500, "开始", 0) = True Then
    TracePrint "找到在 " & LocalOCR.LastFindX & "," & LocalOCR.LastFindY
End If
